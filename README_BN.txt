Kazi Travels & Tours — Android App Project

এই ZIP-এ Android Studio প্রজেক্টের সোর্স কোড আছে। এই পরিবেশে Android SDK/Gradle ইনস্টল না থাকায় APK ফাইলটি এখানে কম্পাইল করা যায়নি। Android Studio দিয়ে APK বানানো যাবে।

APK বানানোর ধাপ:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. ZIP ফাইলটি Extract করুন।
3. Android Studio খুলে Open নির্বাচন করে KaziTravelsAndroid ফোল্ডারটি খুলুন।
4. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন। SDK 35 চাইলে Android Studio-র SDK Manager থেকে Android SDK Platform 35 ইনস্টল করুন।
5. মেনু থেকে Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
6. Build সফল হলে app/build/outputs/apk/debug/app-debug.apk ফাইলটি পাবেন। ফোনে পাঠিয়ে ইনস্টল করতে পারবেন।

নোট:
- অ্যাপটি বর্তমান Kazi Travels & Tours Apps Script ওয়েবসাইট খুলবে।
- WhatsApp/বাহ্যিক লিংক ফোনের উপযুক্ত অ্যাপ বা ব্রাউজারে খোলার চেষ্টা করবে।
- ওয়েবসাইটের Apps Script deployment অবশ্যই চালু থাকতে হবে।
